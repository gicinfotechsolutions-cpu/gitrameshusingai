# Contact page demonstration

A responsive, standalone contact page built with HTML, CSS, and JavaScript.

Open `index.html` in a browser to view the page. No installation or build step is required.

The form includes required-field and email validation, a message character counter,
and an accessible demo confirmation. It runs entirely in the browser: submissions
are not sent, saved, or logged. The displayed email address is a placeholder.
JavaScript is required to try the submission. The FAQ works without JavaScript.

Files:

- `index.html`: contact page and FAQ.
- `styles.css`: desktop and mobile layouts.
- `contact.js`: local demo form behavior.

To accept real inquiries, replace the sample contact information and connect the
form to a backend with server-side validation before enabling real submissions.
